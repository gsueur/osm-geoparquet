US Census boundaries, as GeoParquet

TIGER/Line 2026, starting with the districts of the November elections

The Census Bureau publishes its TIGER/Line boundaries as national GeoPackages, several hundred megabytes each, to download before you can ask anything. Here they are as GeoParquet you query from a URL, one file per layer, with map tiles beside them. The first release is the legislative areas: every congressional district of the 120th Congress and every state legislative district.

Columns and codes are the Census Bureau's, unchanged, so they join with every other Census table. Public domain, like the source.

Each file carries TIGER's columns (STATEFP, GEOID, NAMELSAD, ALAND, AWATER and the rest), the geometry in NAD83 (EPSG:4269, geographic: longitude and latitude) and a bbox column declared as the GeoParquet covering. Rows are sorted on a Hilbert curve, so a point lookup reads one small row group, not the whole country.

The congressional district at a point

INSTALL httpfs; LOAD httpfs; INSTALL spatial; LOAD spatial;
SELECT GEOID, NAMELSAD
FROM read_parquet('https://parquetry.geomermaids.com/census/tiger/2026/legislative/cd120.parquet')
WHERE bbox.xmin <= -97.74 AND bbox.xmax >= -97.74
  AND bbox.ymin <= 30.27 AND bbox.ymax >= 30.27
  AND ST_Contains(geometry, ST_Point(-97.74, 30.27));

House seats per state

SELECT STATEFP, count(*) AS seats
FROM read_parquet('https://parquetry.geomermaids.com/census/tiger/2026/legislative/cd120.parquet')
WHERE CD120FP NOT IN ('98', 'ZZ')   -- delegates, undefined areas
GROUP BY 1 ORDER BY 2 DESC;

More of TIGER/Line

The Census Bureau publishes twelve national GeoPackages for 2026, from rails to census blocks. The legislative areas are the first; the others follow under the same layout, census/tiger/2026/<product>/<layer>.parquet, in the same catalog.
